Cytoscape Web is live!


We are excited to announce the official release of Cytoscape Web, a 100% web-based version of Cytoscape that supports modern computing environments without the need for software installation. The software release is accompanied by a peer-reviewed article recently published in Nucleic Acid Research.
We have also created a detailed Cytoscape Web Manual to help new and returning users get started, access it from the web application's "Help" menu. Cytoscape Web is still in active development and some features might not be available or fully functional yet... Stay tuned to NDEx and the Cytoscape website for more information.
